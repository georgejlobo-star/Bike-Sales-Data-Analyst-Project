Bike Sales Data Analyst Project
Overview
This project is an end-to-end data analytics case study focused on analyzing bike sales, customer behavior, pricing trends, and business performance using SQL and Power BI.
The goal of the project was to:


Clean and prepare raw sales data


Perform exploratory and business-focused analysis


Create interactive dashboards in Power BI


Generate actionable business insights


Build a portfolio-ready analytics project for GitHub

Project Workflow
1. Data Collection
The dataset contains bike sales information including:


Customer demographics


Product categories


Order information


Pricing data


Revenue and demand metrics



2. Data Cleaning
The dataset was cleaned and transformed before analysis:


Removed duplicates


Handled missing values


Standardized column formats


Fixed inconsistent data entries


Created calculated columns and measures



3. SQL Analysis
SQL was used to:


Aggregate sales metrics


Analyze customer purchasing behavior


Calculate revenue trends


Identify top-performing products


Explore pricing and demand relationships


Example business questions:


Which products generated the highest revenue?


Which customer segments purchased the most bikes?


How did pricing changes impact demand?


What were the monthly sales trends?



4. Power BI Dashboard
An interactive dashboard was created in Microsoft Power BI featuring:


KPI cards


Revenue trend analysis


Product performance charts


Customer segmentation visuals


Geographic insights


Interactive filters and slicers



Key Insights
Price Elasticity Observation
One notable finding from the analysis:


A 25% increase in price resulted in a 64% increase in demand. 


This suggests that demand for certain products may be relatively inelastic or influenced by additional external factors such as:


Product popularity


Seasonal demand


Brand perception


Market trends
